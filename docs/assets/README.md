# README artwork

The logo and paper figures are shared with the public [Skill Training project page](https://skilltraining-project.github.io/), copied on September 27, 2026.

- `logo.png`: project logo.
- `framework.png`: corruption and reconstruction framework.
- `training-curve.png`: held-out structure score and skill-library updates during training.
- `transfer.png`: cross-model skill-library transfer results.
- `teaser.gif`: a 22-second animation of the method, converted from the video on the project page (silent, 960 px wide, 15 fps). The animation was made by the authors from the framework figure; its training curve uses the Figure 6 data and its screenplay lines are illustrative.

For the experimental setup and figure captions, see the [author's paper PDF](https://skilltraining-project.github.io/assets/paper.pdf?v=473e0fa1818b).
